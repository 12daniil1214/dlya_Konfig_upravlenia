# dlya_Konfig_upravlenia
## Эмулятор работы в командной строке UNIX-подобной ОС
## Этап 1: REPL
Цель: создать минимальный прототип. Большинство функций в нем пока 
представляют собой заглушки, но диалог с пользователем уже поддерживается. 
## Возможности
- Графический интерфейс, заголовок содержит имя VFS
- Парсер команд с корректной обработкой по пробелам через shlex
- Команды-заглушки: ls, cd - печатают имя и аргументы
- Команда exit - закрывает окно
- Обработка ошибок: неизвестная команда, незакрытые кавычки, пустой ввод
## Этап 2: Конфигурация
Цель: сделать эмулятор настраиваемым, то есть поддержать ввод параметров 
пользователя в приложение. Организовать для этого этапа отладочный вывод всех 
заданных параметров при запуске эмулятора.
## Возможности
- Параметры командной строки: --vfs-path, --log-file, --script
- Отладочный вывод всех заданных параметров при запуске (`[debug]`)
- Команда conf-dump - выводит параметры в формате ключ=значение
- Логирование каждой вызванной команды в CSV-файл с датой и временем
- Выполнение стартового скрипта
- Остановка стартового скрипта при первой ошибке
- Скрипты test_params.bat и test_errors.bat для проверки параметров
## Этап 3: VFS
Цель: подключить виртуальную файловую систему (VFS).
## Возможности
- Загрузка VFS из JSON-файла в память
- Источником служит JSON-документ с деревом узлов (dir / file)
- Исходный файл только читается и никогда не модифицируется
- Поддержка двоичных данных через base64
- Обработка ошибок VFS: несуществующий путь, отсутствие VFS
## Этап 4: Основные команды 
Цель: поддержать команды, имитирующие работу в UNIX-подобной 
командной строке.
## Возможности
- Реализованы команды ls cd
- Добавлены команды who и whoami
- Обработка ошибок: несуществующий путь, файл вместо каталога
- Обновлён startup.txt: примеры всех команд этапа и обработки ошибок
## Этап 5: Дополнительные команды
Цель: поддержать более сложные команды, изменяющие состояние VFS, при 
этом модификации должны осуществляться только в памяти.
## Возможности
- Команда rm для удаления файлов
- Ключ -r для рекурсивного удаления каталогов
- Каталоги без -r не удаляются
- Запрет на удаление ., .., /
- Обработка ошибок: нет такого файла, каталог без -r
- Обновлён startup.txt: примеры всех режимов rm и ошибок
- Модификации только в памяти — исходный JSON не изменяется
